# 🎰 NEON TYPING - HIGH ROLLER TIME ATTACK

カジノのスロットマシンとタイピングゲームを融合させた、60秒間のタイムアタック型ウェブゲームです。  
正確で素早いタイピングによってスロットを回し、ハイスコアと連続コンボ（COMBO）を目指します。

---

## 🌟 主な機能

- **タイピング × スロットシステム**
  - ワード入力に成功するとスロットの絵柄が揃うチャンスが発生します。
  - 「777」が揃うとジャックポット（WIN!）が発生し、一気に **+500pt** を獲得できます。
  - タイプミスをするとコンボがリセットされ、スロットも強制停止（MISS）となります。

- **モード遷移メカニズム（HEAVEN / NORMAL / HELL）**
  - ゲーム状況やコンボ数に応じて内部モードが変化します。
  - **HEAVEN MODE**: スロットの当選確率が大幅にアップする高確率モード。

- **直感的な操作感**
  - **[ SPACE ] キー** でいつでも即座にゲームを開始・リセット可能。
  - Web Audio API によるリアルな操作音・演出音（タイピング音、回転音、ファンファーレ等）。

- **ローカル保存機能（localStorage）**
  - **アクセスカウンター**: ページの訪問回数を記録・表示。
  - **プレイヤーコメント掲示板**: 自分の名前とメッセージを投稿可能（個別のコメント削除機能付き）。

---

## 🎮 遊び方

1. ページを開き、**[ SPACE ] キー** または画面上の入力欄をクリックしてゲームを開始します。
2. 画面に表示されるローマ字に従って、正確にキーボード入力を行ってください。
3. 制限時間（60秒）が終了すると、最終スコアと詳細なプレイ結果（最大コンボ、成功数、ミス数）が表示されます。
4. リザルト画面で **[ SPACE ] キー** を押すと、即座に次のプレイを開始できます。

本プロジェクトは単一の HTML ファイル（`index.html`）で完結しているため、特別なビルド環境やサーバー設定は不要です。

1. 当リポジトリをクローンまたは ZIP ダウンロードします。
